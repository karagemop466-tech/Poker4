Figures use the official Venetian/Palazzo poker-rate terms ($55 resort fee + tax; 13.38% room tax). Formula used

True hotel cost per night

true cost/night = base rate + resort fee + (base rate + resort fee) × tax rate

Example with Venetian terms: $119 + $55 + ($119 + $55) × 13.38% = $197.28/night.
