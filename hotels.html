Like-for-like comparison rules used here
  • True cost per night = nightly rate + mandatory resort fee + tax at 13.38% on (rate + fee). Resort fees are mandatory, so they are never treated as optional.
  • Rates are logged with dates. Each capture keeps check-in/check-out, nightly amounts verbatim, resort fee, taxes and the checkout total — appended to a rate log, never overwritten. Comparison dates for like-for-like: the same stay window (Nov 27–30, 2026) captured 2026-11-17.
  • Blank + flagged beats guessed. Where an official source does not state a resort fee, parking or cancellation deadline, the cell says "blank + flagged" (see F9–F10). Secondary sources conflict for Caesars ($49.95 vs $54.95) and ARIA ($50 vs $55) — both stay blank.
  • Walking times are verified only where an official source establishes the location (Venetian poker room is inside The Palazzo). For all other pairs, use the per-row Google Maps walking link and record the result — the ≤30-minute filter (brief item 20) activates only on verified rows.
