Compute the true cost

(official room subtotal + mandatory resort / destination fees + taxes + required property charges) ÷ number of nights

Also calculate the whole-stay total. Include parking only if needed, and keep optional spend separate. Capture cancellation terms, deposit/payment timing, resort-fee tax treatment, and any discounts/eligibility conditions. Use the checkout total or request an itemized quote; a search-result teaser is not a confirmed price.
