Suggested decision path

  1. Fix trip dates and nightly budget/quality floor.
  2. For candidate event(s), get official structure sheet and written maximum-entry / no-rebuy / no-add-on rules; remove any not matching single-entry policy.
  3. Compare only surviving events on guaranteed pool, buy-in, starting stack/blind duration, payout structure, and daily schedule fit.
  4. Obtain itemized hotel totals for the same stay; check walking route under 30 minutes.
  5. Build one event per day first; add evening events only where the player can realistically exit the earlier event.
  6. Reconfirm official schedules, rates, and policies before nonrefundable payment.
