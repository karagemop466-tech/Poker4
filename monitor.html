Change monitor — scheduled official-source re-check

The repository ships a scheduled GitHub Actions workflow (.github/workflows/monitor.yml) that runs every morning (14:00 UTC ≈ 6:00–7:00 AM PT). It re-fetches every official URL below with tools/monitor_sources.py, stores a content hash and excerpt snapshot, appends any differences to data/change_log.json, and commits the result. Rows whose source changed appear here with a SOURCE CHANGED marker and carry a badge on the Tournaments/Hotels pages after the next site build.

How to read it: a change entry means the official page content moved — not that a value necessarily changed. Open the source link, compare the excerpt, then update the row (and this log) deliberately. Changed rows are marked, never silently rewritten.

Daily schedule feed
