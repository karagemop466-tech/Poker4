Recommended sequence (matches the project's trip workflow)

  1. Fix trip dates and the nightly budget/quality floor. Everything else keys off this.
  2. For candidate events, obtain the written maximum-entry / no-rebuy / no-add-on rule and drop any event that does not match a single-entry policy.
  3. Compare only surviving events on guarantee, total entry fee, starting stack / blind duration, payout structure and daily fit.
  4. Capture itemized hotel totals for the same stay and confirm the walking route is under 30 minutes (verified matrix already covers 14 pairs).
  5. Build one event per day first; add an evening event only where you can realistically exit the earlier one.
  6. Reconfirm official schedules, rates and policies right before any nonrefundable payment — the daily source monitor flags changes.
