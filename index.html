Executive summary

The current window contains the Venetian DeepStack Extravaganza IV (Nov 16 – Dec 23, 2026; $3.6M+ in stated guarantees) and the Wynn WPT World Championship (Nov 27 – Dec 21, 2026). Every Venetian structure sheet (37) and every Wynn daily/WPT terms page was read from official PDFs on 2026-11-17. Not a single event is confirmed single-entry/freezeout: Venetian sheets never state an entry-count rule (one sheet even references “subsequent buy in’s”), and every Wynn daily explicitly allows re-entry (the Friday event adds unlimited rebuys and an add-on). Those spend-advantage events are kept in their own sections.

Single-entry recommendation status: no event can yet be recommended or ranked as a confirmed single-entry tournament. The tournament tables retain confirmed entry/guarantee arithmetic as descriptive reference only, while entry-policy-unknown, re-entry, flight, bounty and satellite events remain separated and labeled. Obtain written maximum-entry / no-rebuy / no-add-on terms before ranking candidates.

Hotels: The Venetian is the only property with a fully verified cost picture ($55 + tax resort fee, 13.38% Clark County tax, $20/day self-parking, cancellation terms, conditional poker rates from $119/$209 with a play requirement). Verified walks: Venetian-bound cross-property routes are ≤30 min except ARIA (31 min); Wynn-bound routes are ≤30 min except Bellagio (32 min) and ARIA (42 min). Wynn internal hotel-to-poker-room time remains unmeasured. The trip calculator uses only user-provided rates and dates, plus verified fees; no stay quote or occupancy is assumed.

Daily plan: the Daily plan gives each day a primary event and a conditional fallback using verified start times, verified late-registration cutoffs and labeled duration estimates; overlapping pairs are flagged rather than sequenced impossibly. Note: no official schedule shows an 8:00 AM start in this window; the earliest verified starts are 9:10–10:10 AM.

How to use this site

  • Tournaments — every event with filters: text search across all tables, date selector, and a “single-entry / freezeout confirmed” toggle (currently matches 0 rows — by verified data, not by omission).
  • Hotels — dated rate log, resort fee + tax + parking + cancellation fields, walk-time matrix with a ≤30-min filter, official per-date booking links.
  • Trip calculator — entries × buy-ins + nights × true hotel cost.
  • Venue pages — one per venue with its events and nearby hotels.
  • Change monitor — official URLs re-checked on a schedule; changed sources flagged.
  • Questions and Suggestions — what must be answered before nonrefundable decisions, and a reviewable suggestion queue.
