Executive summary

  • Series on the Strip, Nov 16 – Dec 23, 2026: Venetian DeepStack Extravaganza IV (official series line: “More than $3.6 Million in guaranteed tournament prize pools”) overlaps the Wynn WPT World Championship series (Nov 27 – Dec 21, printed on the official structures PDF).
  • Single-entry status — the honest result: all 37 Venetian structure sheets and the Wynn daily/WPT structures were read line-by-line. No document states a maximum-entry, no-re-entry, freezeout, or add-on policy for any Venetian event, so no row can be labeled “confirmed single-entry”. Worse for the plan: every Wynn daily tournament officially allows re-entry/add-ons, and every WPT-series event read so far allows unlimited re-entry. The “single-entry / freezeout confirmed” filter therefore returns zero rows — displayed honestly instead of filled by inference (Flagged F1–F3, F7).
  • What IS verified per row: buy-in, house fee, prize-pool contribution, guarantee (and whether it includes bounty money), starting stack, level duration, late-registration cutoff, start time and dates — all with the official excerpt and retrieval date, and a scheduled daily re-check of every source URL.
  • Best verified value ratios (guarantee ÷ buy-in, descriptive only, prize-pool basis): Venetian $600 NLH 1-day events #28 ($40K GTD = 66.7×), #14/#63 ($30K = 50×); $400 NLH #10 ($15K = 37.5×); $300 NLH #2/#12 ($10K = 33.3×); $800 WPT event Nov 30–Dec 2 ($1M GTD = 1250×, but unlimited re-entry confirmed). Ranking exists only where buy-in + guarantee are both officially printed; four $200 events print no guarantee anywhere and are excluded (Flagged F5).
  • Day planning: the earliest official starts are 9:10 AM (Turbo satellite #46), 10:10 AM (RaceDay/Seniors/Day-1A flights) and 11:10 AM for most 1-day events. No 8 AM event exists on any official schedule (Flagged F12). The schedule planner builds each day from the earliest official start, gives the primary anchor + conditional fallbacks, and flags possible overlaps using late-registration windows because finish times are never officially published.
  • Hotels — true cost: verified so far: Venetian resort fee $55/night + tax (official page, 2026-11-16); Treasure Island officially headlines a “$69* NIGHT + NO RESORT FEE” package with free parking (footnotes pending — Flagged F8). Room rates are dynamic, so the site ships a dated rate log + official booking links instead of stale numbers. A ≤30-minute walking filter applies to labeled mapping estimates with Google Maps evidence links (Flagged F10).
  • Trip calculator: entries × buy-in + nights × (rate + resort fee + tax). The 13.38% tax rate is user-provided and still needs verification against your real checkout total (Flagged F9).

How to use this dashboard

Pick tournaments

On Tournaments: search everything, filter by date or venue, toggle “single-entry / freezeout confirmed”, and read the separate sections for confirmed re-entry/add-on events and satellites. Every row carries its official source link and a last-checked date.

Build days

On Schedule planner: choose a date to get that day’s sessions in start-time order with the primary event, conditional fallback, late-registration cutoffs, and possible-overlap flags.

Cost it out

On Hotels & cost: filter hotels by a ≤30-minute walk to the venue, use the true-cost and trip calculators (entries × buy-ins + nights × true hotel cost), and append dated entries to the rate log rather than trusting a single number.

Check the fine print

Flagged for Review lists every irregularity with sources (official-page typos, ambiguous WPT dates, missing guarantees, unreachable official pages). Questions lists what must be answered before money is committed; Suggestions awaits your choices before any change is implemented.

Read before paying anything: no event on this site is confirmed single-entry; several officially allow re-entry. Before non-refundable payment, get written per-event entry policy from the poker room, capture an itemized hotel checkout total, and re-check the official schedules (the site re-checks URLs daily; changed rows are flagged).
