Dashboard / Re-entry & add-on

Every event where money buys chips — kept separate, on purpose

The brief was single-entry only, with anything that lets a player gain an advantage by spending more held in a separate section. This page is that section. These events are not “bad” — they are simply a different game from a freezeout, and mixing them into a single-entry ranking would make the ranking meaningless.

The distinction that matters. “No re-entry” is not the same as “no spending advantage”. Wynn's Friday $240 explicitly bars re-entry yet still offers unlimited $200 rebuys and a $100 add-on. Bellagio's Friday $600 allows re-entry and sells a $40 “voluntary staff gratuity” that adds 15,000 chips. Both belong here; neither belongs in the single-entry list.

The one single-entry-per-flight event on the Strip

published

WPT World Championship — $10,400, Dec 13 / 14 / 15 flights

The organiser's own release says players are allowed “a single entry per starting flight”, with the last chance to enter before the start of Day 2 (WPT release). There are three starting flights, so a determined player can still enter three times across the event. It is the closest thing to a guaranteed freezeout this dataset contains — and it is a $10,400 decision, not a $300 one.

Contrast: the $400 Super Gold Million in the same festival is explicitly “unlimited re-entry”. Same room, same month, opposite rule — which is why each event has to be checked on its own sheet.

How the filter behaves on the tournaments table

The tournaments page has a checkbox labelled official single-entry rule only. Today it returns zero Venetian rows, because no Venetian 2026 sheet states a rule. That is the honest output, not a bug. Once a poker room confirms a rule in writing, adding it to data/v2/events.json and rebuilding flips that row into the filter.

How to read this site. A value is shown only if a session runner read it on the official page linked in that row, on 2026-11-17. Everything else says UNVERIFIED and appears on the Flagged for review page with its source links. Walking minutes are OpenStreetMap/OSRM foot-routing estimates between property centroids — not a casino publication and not Google or Apple Maps. Guarantee ÷ buy-in is arithmetic, not a forecast.
