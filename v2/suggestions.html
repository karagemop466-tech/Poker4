Suggested improvements — decide the path before changing the site

Nothing on this page has been implemented. Each suggestion states what it would change about a real decision, how much work it is, and whether it is recommended. Pick the ones you want and they become the next build's scope.

Recommended path, if you only pick three.
  1. S1 — get the Venetian entry rule in writing. It converts 83 unverified rows into a usable single-entry list and costs one phone call.
  2. S2 — read the Wynn WPT per-event structure sheets to fill 134 missing fee values. That is the difference between a listed buy-in and a true cost.
  3. S3 — capture one real date-specific hotel checkout total per property. Until then every hotel number is a floor, not a quote.

Deliberately not suggested

Auto-scraping the Venetian calendar or the Wynn PDFs was considered and is not recommended yet: both are official sources with no machine-readable API, and a scraper that silently fails would turn “unverified” into “looks verified”. If it is built, it must write the same retrieval date and excerpt for every value it captures, exactly like the manual log on this site.

How to read this site. A value is shown only if a session runner read it on the official page linked in that row, on 2026-11-17. Everything else says UNVERIFIED and appears on the Flagged for review page with its source links. Walking minutes are OpenStreetMap/OSRM foot-routing estimates between property centroids — not a casino publication and not Google or Apple Maps. Guarantee ÷ buy-in is arithmetic, not a forecast.
