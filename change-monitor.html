Scheduled re-check of official sources

Official URL change monitor

Each official URL used by this dashboard is listed below with its last-checked date and re-check interval. When a source is re-checked and a displayed value differs from the previously recorded value, the affected rows are flagged as changed. This is a static GitHub Pages site — there is no server-side cron, so re-checks are performed manually (or by a future scheduled action) and recorded here.

How change monitoring works

  1. Each URL has a check interval (e.g., 7 days for schedules, 30 days for fee/terms pages).
  2. On re-check, the value displayed on the official page is compared with the previously recorded value.
  3. If a value changed, the Changed column is set to yes and every table row that cites that source is flagged for review.
  4. If no change is confirmed, Last checked is advanced and Changed stays no.

How a changed source affects rows

If, for example, the Venetian schedule PDF is updated and a guarantee or start time changes, every tournament row that lists that PDF as a source receives a Source changed — re-verify flag. Rows are not silently edited; the previous value is retained alongside the new check date so you can decide which value to trust.

URLs and intervals are set from the sources in data/tournaments.json and data/hotels.json. Automated fetching is not part of this static site; see Suggestions for the scraping/automation discussion.
