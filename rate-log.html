Capture checklist for an exact-date quote (compare like-for-like)

  1. Same dates + same occupancy on each official booking engine (links on the Hotels page).
  2. Record: checkout total, nightly average, mandatory resort fee + tax, parking, cancellation deadline, rate timestamp.
  3. Compute true cost/night = (rate + resort fee) × 1.1338 and compare — never compare a bare rate against an all-in total.
  4. Append the capture to this log with its source link and timestamp.
