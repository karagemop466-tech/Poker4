How change monitoring works

  • Scheduled re-check: scripts/scrape_daily.py fetches each official URL in the sources registry (GitHub Actions cron, daily) and hashes the returned text. A changed hash marks the affected rows changed and writes an entry here with the URL and timestamp.
  • Dated rate log: hotel rate captures are appended (date-stamped) to each hotel's rate log — old captures are never overwritten, so rate movement over time is visible.
  • Value-level diffing: when a schedule/structure page changes, the row is flagged "changed since last check" until re-verified; see Suggestion S9 for parsing-level diffs (not implemented).
  • Local run: python3 scripts/scrape_daily.py (writes data/feature/changes.json + row flags; no external services needed).
