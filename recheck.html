Official-source re-check status

Every official URL cited by this site is re-fetched on a schedule by .github/workflows/recheck.yml (daily, via scripts/recheck.py). The content hash of each page is compared with the previous run: changed means the source moved and every row citing it must be re-verified before being trusted; unchanged means the live page still matches what this site records; pending means the baseline snapshot (16 Nov 2026) is recorded but the scheduled run has not processed it yet.

What happens on a change

  1. The daily workflow flags the URL as changed in the log and warns in the run summary.
  2. Every table row citing that URL is treated as unverified until a human re-reads the source and updates the value with a new “last checked” date.
  3. Nothing is auto-overwritten: values only change after an explicit re-verification pass, per this project's no-hallucination rule.
