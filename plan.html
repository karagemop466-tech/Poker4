One day, one primary event, one conditional fallback

Sequencing uses only what the calendar prints: the start time, the “REG CLOSES” column and the Day-2 restart rows. A day gets a primary event and a fallback that is only reachable if you are done with the first — that means its start is at or after the primary's registration deadline, the closest thing to a guaranteed exit the official data offers. No event duration is invented: where a sheet lists levels, the implied length sits on the tournament row, and it is never used to reorder this plan.
