Sequence & overlap

One primary event per day — plus a conditional fallback.

Each day gets a primary event (the best single-day candidate) and, where one exists, a conditional fallback for later that day. Because official finish times are not published, two same-day entries cannot be confirmed playable in sequence — so no day is shown as an impossible back-to-back. An 8 AM-to-all-day schedule is not available: the earliest verified start is 9:10 AM (satellite #46, Dec 12).

Overlap rule: flagged when two events on the same day cannot be confirmed to run in sequence. Start time and late-registration cutoff are verified from structure sheets, but plausible event duration is not published, so the fallback is always labeled conditional.
