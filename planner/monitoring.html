Change monitoring

Official URLs re-checked on a schedule — changes flagged.

Each official source is re-checked automatically and a last-checked date is recorded per row. When a value changes, the change is appended to the dated log below and the affected row is flagged. Run python3 tools/check_sources.py locally, or let the scheduled GitHub Actions workflow run it each morning.

How it runs: .github/workflows/monitor.yml runs tools/check_sources.py on a schedule (cron). The script fetches each source URL, compares the response to the stored snapshot, writes a dated change log, and updates each row's last-checked date. tools/scrape_schedule.py pulls each Strip room's official daily schedule each morning and stores a dated snapshot.
